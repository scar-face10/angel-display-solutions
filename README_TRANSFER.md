# Angels Display Solutions — Portable Website Export

This archive contains the complete website at checkpoint `6638ebc73d46980209da96b92b825e03b13ed08b`.

## Included

- Plain HTML, CSS, and ES module JavaScript source
- `assets/` including all local gallery-display originals
- `public/manus-routes.json`
- `server.mjs`, `package.json`, `app.config.ts`, `TODO.md`, and `plan.md`
- 238 files in `assets/gallery-display/`, including the migrated gallery originals with their original filenames, extensions, and bytes

Git internals and installed dependencies are intentionally excluded so the archive can be opened cleanly in another IDE.

## Run locally

Requires Node.js 18+.

```bash
npm run dev
```

Then open `http://127.0.0.1:3000/` or `http://127.0.0.1:3000/gallery.html`.

There are no package dependencies to install for this plain Node.js website.
